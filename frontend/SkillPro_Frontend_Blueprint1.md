# SkillPro Frontend Blueprint (V2)

# 🎨 Design Philosophy

SkillPro is designed to feel warm, premium, and trustworthy. Instead of using the common blue corporate theme, the interface follows a soft neutral design with earthy colors, inspired by modern products like Airbnb, Notion, and Apple. The goal is to create a clean, elegant, and user-friendly experience that feels welcoming to both customers and professionals.

# ✨ UI Style

- Warm and minimal interface
- Premium card-based layout
- Soft rounded corners (16px)
- Smooth shadows for depth
- Plenty of whitespace for readability
- Subtle hover animations
- Clean typography using **Poppins** and **Inter**
- Consistent spacing system (8px grid)
- Responsive design for Mobile, Tablet, and Desktop
- Soft earthy color palette for a premium marketplace experience
